What is MetroShip?


MetroShip is a You Ship We Ship program (YSWS) in which you will build a map website using dynamic or static data and OpenStreetMap to recieve a variety of transit-related merchandise!

MetroShip uses Hackatime to track hours spent on building the website(s), and prizes will be awarded at certain time checkpoints and project completion.
